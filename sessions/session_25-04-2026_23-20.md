# Сессия 25.04.2026 — 23:20 МСК

## Стек проекта (финальный)
- **Backend:** Laravel 13 + PostgreSQL 18
- **Публичный сайт:** Blade + Alpine.js + Tailwind CSS
- **Панели (Admin / CRM / Бух):** Vue 3 + Inertia.js + Tailwind CSS
- **TG-бот:** aiogram 3 (Python, webhook через Laravel)
- **Инфраструктура:** OpenPanel, `php artisan serve` (dev), Nginx+PHP-FPM (prod)

## Реализовано

### Планирование
- Создан `todo.md` с полным планом проекта: публичный сайт, админ-панель, бух-панель, CRM, возвраты, интеграции
- Определён порядок разработки и архитектура

### База данных
- Установлен PostgreSQL 18, создана БД `foodstar` и пользователь `foodstar_user`
- Написаны и применены миграции (13 таблиц):
  - `users` (роли: admin / accountant / manager)
  - `categories`, `products`, `product_images`
  - `clients`
  - `orders`, `order_items`
  - `invoices`
  - `returns`, `return_items`
  - `payments`
  - `order_comments`
  - `lead_requests`

### Модели Laravel
- Созданы и заполнены все 12 моделей с `$fillable`, `casts()` и связями (`hasMany`, `belongsTo`)
- `ProductReturn` — `$table = 'returns'` (обход зарезервированного слова PHP)

### Frontend — инфраструктура
- Установлены и настроены: Inertia.js, Vue 3, Vite, Tailwind CSS
- Настроен `@` алиас для импортов
- Подключены шрифты Gilroy (Regular, Medium, SemiBold, Bold, ExtraBold)
- CSS-переменные цветов: `--color-primary: #91b843`
- Созданы layouts: `AppLayout.vue` (панели), `PublicLayout.vue` (публичный сайт)
- Создан `Navbar.vue` для панелей (роль-зависимое меню)

### Публичный сайт — компоненты
- `PublicHeader.vue` — липкий навбар, мобильное меню с анимацией
- `PublicFooter.vue` — три колонки: о компании, навигация, контакты
- `LeadModal.vue` — модалка заявки с состоянием "отправлено"
- `HeroSection.vue` — hero с фоном, заголовком, плашками с зелёным бордером, кнопками
- `CatalogSection.vue` — сетка товаров со статусами (хит/новинка/скидка)
- `PartnersSection.vue` — карточки с фото на фоне
- `LeadFormSection.vue` — отдельная секция с формой заявки (не модалка)
- `GuaranteesSection.vue` — 6 гарантий
- `FaqSection.vue` — аккордеон с плавной анимацией
- `AboutSection.vue` — фото команды + цифры поверх
- `LogisticsSection.vue` — транспортная логистика
- `WhyUsSection.vue` — 5 причин выбрать нас (карточки с фото)
- `StepsSection.vue` — 3 шага работы
- `PromotionsSection.vue` — 3 акции с фото на фоне
- `ContactsSection.vue` — контакты + карта + CTA
